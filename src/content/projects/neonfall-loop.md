This is the living build: Neonfall as the improvement loop has reshaped it, round after round of simulation bands and fresh-critic reviews. The run is structured in five named acts with a scripted opening, the Herald duel runs on printed clocks and escalation, drafting thins to your own build late, and every number on every card is audited against the code each round. It is not finished — the loop publishes it here, as the main build, only when two fresh critics independently score it 9.4 or better. Until then this page is the playtest copy, and the original release stays untouched alongside it as V1.
