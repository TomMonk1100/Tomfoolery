Explain it like I'm 5

Here is a grid of lights. Press one and it flips — but so do the lights directly above, below, left and right of it, like a plus sign. The game is to turn them all off. The twist is that most starting grids cannot be turned off at all, no matter how clever you are — and that is not a feeling, it is algebra. Before you press anything, a bit of maths over the whole grid already knows whether your board is one of the lucky ones. On the classic 5×5 board, only one board in four is.

Why you're looking at this

I built the solver first and the game second, and the solver is exact: it does Gaussian elimination over GF(2) — arithmetic where 1 + 1 = 0, which is exactly what a toggle is. So the "solve" button never guesses, the "am I stuck?" answer is never a shrug, and when the page says a board is impossible it can point at why: there are press patterns that change nothing at all ("quiet patterns"), and a board that overlaps one of them oddly can never be cleared. The game is the toy; the coset structure underneath it is the exhibit.

the exact facts, per size

Computed by the same GF(2) code the game runs — rank and nullity of the press matrix A. A board is solvable exactly when it lies in the image of A — that is, when it is one of the boards you can actually reach by pressing. When a solution exists, the full set of solutions is a coset of the kernel: the kernel is the set of press patterns that change nothing, and each solution drags a whole family of look-alikes with it, got by adding one of those do-nothing patterns. So there are always exactly 2nullity solutions, and exactly 2−nullity of all boards are solvable.

quiet patterns

Press patterns that change nothing at all — the kernel of A, shown live by the solver for the current board size (purple outline button below replays one on your board, if any exist). They are also the impossibility witnesses: a board is unsolvable exactly when it has odd overlap with the effect pattern of one of these. On 3×3 there are none, which is why every 3×3 board is solvable.

notes

  • "New board" never deals you an impossible game: it starts from the dark board and applies random presses, so the board is solvable by construction — the presses that made it are one solution (the solver may find a different one; all solutions differ by quiet patterns).
  • If you scramble a board yourself into an unsolvable one, the solver says so plainly instead of failing silently. Witness you can try on 5×5: clear the board, then light only one corner cell. That board has no solution — verified exhaustively against the algebra in the core's test suite.
  • The 5×5 numbers are the classic ones and they are computed here, not copied: rank 23, nullity 2, so exactly 1/4 of the 2²⁵ boards are solvable and every solvable board has exactly 4 solutions. The sweep behind this page also sampled 4,000 random boards per size and matched the algebra (5×5: exactly 1,000 of 4,000 solvable).
  • 4×4 is the stingy size on this page: nullity 4, so only 1/16 of boards are solvable — but each solvable one has 16 different solutions.
