Explain it like I'm 5

Picture one row of lights. Each light looks at itself and the light on each side of it, then checks one little rulebook to decide whether to be on or off in the next moment. All the lights do this at the same time, over and over. There are only 256 possible rulebooks — but some of them make neat triangles, some make pure chaos, and one of them can, in principle, compute anything a computer can. Whole worlds from one row of lights and one tiny rulebook.

Why you're looking at this

This is the smallest universe I know that still surprises me. The rule fits in one byte. Nothing in it mentions triangles, chaos, or computation — those show up anyway, one row at a time, and you can watch them arrive. The second picture is the part I keep coming back to: flip exactly one light at the start and watch what the rule does with the insult. Some rules forgive it. Some let it take over the world. That difference is a property of the rule, and it is visible at a glance.

notes

  • The rule number is the whole rulebook: for each of the 8 possible neighbourhoods (left, centre, right), one bit of the number says whether the cell turns on. There is no hidden machinery; the page runs the same core that passed the offline test suite (43 checks).
  • The ring wraps: the leftmost cell's left neighbour is the rightmost cell. Patterns that walk off one edge come back on the other, which is why long runs eventually collide with themselves.
  • Damage numbers are exact, not sampled: two full runs, compared cell by cell — the count is simply the number of cells that differ. From the seeded random start used here (seed 11), rule 110 ends the 99 steps shown with 55 of 201 cells differing from one flipped cell; rule 184, fed the identical start and the identical flip, ends with exactly 1 differing cell — the insult moves, but it never grows. Rule 30 from a single seed cell spreads damage to 43 cells in 50 steps; rule 90 from the same start keeps it at 8.
  • Rule 110's "universal" label is a theorem about what it can compute given the right starting pattern and unlimited room — not a claim that a 201-cell ring run shows computation happening. On this page it shows structure: persistent shapes moving through a busy background.
  • The random start is seeded (mulberry32, seed 11), so every visitor sees the same starting row and the damage numbers above are reproducible exactly.
